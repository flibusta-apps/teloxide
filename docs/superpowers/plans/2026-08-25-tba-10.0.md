# Telegram Bot API 10.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Raise teloxide's supported Telegram Bot API version from 9.6 to 10.0.

**Architecture:** Keep object types hand-maintained in `teloxide-core/src/types`, describe methods in hand-written `schema.ron`, and run repository codegen tests to refresh generated request artifacts. Integrate the new guest-message update through the low-level model and high-level dispatcher filters, then update manual requester adaptors and release documentation.

**Tech Stack:** Rust, serde, serde_json, schemars test schemas, RON, Cargo and Just.

---

## Authoritative scope

Use the Bot API page archived on May 15, 2026. It is the 10.0 API snapshot;
do not use the current page because it includes changes from 10.1--10.3.

New response objects: `SentGuestMessage`, `BotAccessSettings`, `LivePhoto`,
`PaidMediaLivePhoto`, and `PollMedia`.

New input objects/unions: `InputMediaLivePhoto`, `InputPaidMediaLivePhoto`,
`InputMediaSticker`, `InputMediaLocation`, `InputMediaVenue`,
`InputPollMedia`, and `InputPollOptionMedia`.

New methods: `answerGuestQuery`, `getManagedBotAccessSettings`,
`setManagedBotAccessSettings`, `getUserPersonalChatMessages`,
`deleteAllMessageReactions`, `deleteMessageReaction`, and `sendLivePhoto`.
